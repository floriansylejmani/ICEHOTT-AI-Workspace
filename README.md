# ICEHOTT AI Workspace

ICEHOTT is a production-oriented AI workspace for agentic work: chat, knowledge, tools, workflows, approvals, artifacts, and observability in one product.

## Phase 0 status

- Next.js 16 frontend
- ASP.NET Core API with Clean Architecture project boundaries
- Python FastAPI AI service
- PostgreSQL + pgvector
- Redis
- Docker Compose
- GitHub Actions CI
- Health/readiness endpoints
- Security and architecture baseline docs

## Local services

- Web: http://localhost:3000
- API: http://localhost:5050
- AI service: http://localhost:8000
- PostgreSQL: localhost:5432
- Redis: localhost:6379

## Validation

Run backend tests, frontend lint/build, AI tests, and Docker configuration checks before merging changes.
